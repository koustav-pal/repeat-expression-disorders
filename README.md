# Repeat-containing introns are prognostic biomarkers in ALS

This repository contains all of the code required for running the analysis outlined in the article titled `Repeat containing introns are prognostic biomarkers in amyotrophic lateral sclerosis` co-authored by Pal et al. 202x. Due to constraints on file sizes, only scrips are listed here and the steps necessary to perform each analysis is outlined below. Future users will need to set up their own paths to make use of these scripts

## Analysis descriptions

### 1.0 Identification of expanded repeats within the human genome

Scripts necessary for identifying expanded repeats within the human genome are stored within directory `repeat-expression-disorders/00-manuscript/01-repeat-characterisation/scripts/`. In sequential order of execution: 

1. `repeat-expression-disorders/00-manuscript/01-repeat-characterisation
/scripts/00-write-genic-sequences.R`: Uses the ENSEMBL transcriptome annotation version 104 to extract FASTA sequences of *genes* from the reference human genome (hg38).
2.  `repeat-expression-disorders/00-manuscript/01-repeat-characterisation
/scripts/01-run-kmer-ssr.sh`: HPC configured script that uses [Kmer-SSR](https://github.com/ridgelab/Kmer-SSR) to detect expanded repeat sequences in the genic FASTA sequences generated at the previous step.

These output tables generated by [Kmer-SSR](https://github.com/ridgelab/Kmer-SSR) are converted back into genomic coordinates using the steps outlined within `repeat-expression-disorders/00-manuscript/00-analysis-markdowns/final_figures/scripts/01-prepare-figure-1A.rmd`
